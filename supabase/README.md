# Database

Supabase (PostgreSQL + PostGIS) schema for places, votes, reviews, reports and
moderation. Clients only call `SECURITY DEFINER` functions; every table has
row-level security.

| Path | Contents |
| --- | --- |
| `migrations/` | extensions, schema, functions (RPC API, triggers), security, cron |
| `seed.sql` | halal places from OpenStreetMap (ODbL), generated by `python -m geovox seed-places` |
| `tests/` | pgTAP suite (59 assertions) |
| `test-shim/` | minimal `auth` schema and roles to run the suite on plain PostgreSQL |
| `config.toml` | Supabase CLI configuration for a local stack |

```bash
bash ../scripts/test-db.sh      # migrations + pgTAP on PostgreSQL 16 / PostGIS / pgTAP
supabase start && supabase db reset   # local Supabase stack (Docker)
```
